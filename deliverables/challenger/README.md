## پیش از باز کردن فایل — مهم

فونت **Vazirmatn** را از پوشهٔ `fonts/` نصب کنید (روی ویندوز: انتخاب فایل‌ها → راست‌کلیک → Install).
اگر نصب نباشد، پاورپوینت فونت جانشین می‌گذارد و چیدمان عنوان‌ها جابه‌جا می‌شود؛ متن‌ها سالم می‌مانند اما ظاهر دک عوض می‌شود.
فونت در فایل **جاسازی (embed) نشده** است، چون python-pptx از embed پشتیبانی نمی‌کند.

## بازتولید دک

```bash
python3 -m venv .venv
.venv/bin/pip install python-pptx==1.0.2 pillow uharfbuzz fonttools matplotlib
VAZIR_DIR=./fonts .venv/bin/python build_deck.py      # pptx + فیت‌پس متن
VAZIR_DIR=./fonts .venv/bin/python check_titles.py    # بازرسی عنوان‌ها
VAZIR_DIR=./fonts .venv/bin/python render_preview.py  # PNG/PDF پیش‌نمایش
```

| فایل | نقش |
|---|---|
| `deckkit.py` | تم، اندازه‌گیری متن، اسلایدسازی |
| `build_deck.py` | محتوای ۱۳ اسلاید + اسپیکرنوت |
| `fit.py` | پاس اصلاح سرریز متن پس از ساخت |
| `check_titles.py` | بازرسی عنوان‌ها (خط یتیم، تعداد خط) |
| `render_preview.py` + `shaping.py` | رندر پیش‌نمایش با شکل‌دهی واقعی فارسی |

## حق نشر تصاویر

عکس‌ها از آرشیو عمومی وب (Carscoops، HotCars، Curbside Classic) گرفته شده‌اند و
**حق نشرشان متعلق به صاحبان اصلی است**. برای استفادهٔ تجاری یا انتشار عمومی،
تصاویر را با عکس‌های دارای مجوز (خریداری‌شده یا استوک) جایگزین کنید.
جای هر تصویر در `assets/` با همان نام قابل تعویض است و نسبت برش خودکار حفظ می‌شود.
